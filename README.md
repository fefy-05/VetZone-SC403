# VetZone

## Descripción

VetZone es un sistema web para la gestión de clínicas veterinarias que permite administrar usuarios, mascotas, citas médicas, expedientes clínicos, vacunas, inventario y facturación.

## Tecnologías

* Java 21
* Spring Boot
* Thymeleaf
* Bootstrap 5
* Hibernate / JPA
* MySQL
* Spring Security
* Git y GitHub
